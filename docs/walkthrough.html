04 / safety line

No imaginary armor

read before use

The browser state is synthetic and does not inspect this machine. The real CLI checks whether bwrap is available at run time.

  • Fallback runs the requested command directly with timeout and output bounds.
  • Fallback does not enforce filesystem or network isolation.
  • Even enforced bubblewrap is an observation of this invocation, not a complete security guarantee.

If the flag says fallback, believe it. The honest receipt is the feature.
