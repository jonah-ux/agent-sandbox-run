04 / safety line

No imaginary armor.

read before use

Synthetic page only; it does not inspect this machine. The CLI probes bwrap at run time.

  • Fallback runs the requested command directly with timeout and output bounds.
  • Fallback does not enforce filesystem or network isolation.
  • Even enforced bubblewrap is evidence about this invocation, not a complete security guarantee.

If the flag says fallback, believe it. The honest receipt is the feature.
